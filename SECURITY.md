# Security Policy

## Supported versions

Fixes are released as a new version. Older versions are not patched.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
through GitHub's [private vulnerability reporting](https://github.com/mariusgrote/pdf-lib/security/advisories/new).

Include a description of the problem, the affected version, and if possible a
minimal PDF or script that reproduces it.

Parsing untrusted PDFs is the most likely source of problems (for example
excessive memory use or endless loops on malformed files). Reports for these are
welcome.
